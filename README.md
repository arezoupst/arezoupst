## What I've Built & What I'm Exploring

I’ve worked on projects across bioinformatics, machine learning, and healthcare AI — from multi-omics analysis and predictive modeling to AI-powered healthcare applications.

My work includes a Siamese neural network for gestational-age prediction using multi-omics data, machine learning workflows for breast cancer classification, and biological sequence analysis with Python and Biopython. At Learnify Health, I’ve also worked on AI-powered healthcare education, including document retrieval, semantic search, and interactive virtual-patient applications.

I’m currently expanding my ML engineering skills through hands-on projects, with a focus on PyTorch, RAG, and LLM-based applications. I’m particularly interested in building practical, well-structured systems and learning by turning ideas into working projects.
